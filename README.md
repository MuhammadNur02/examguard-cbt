ExamGuard CBT 🛡️Sistem ujian daring (Computer Based Test) berbasis web yang dirancang untuk meminimalkan celah kecurangan peramban dan mempercepat proses evaluasi tugas/ujian esai.Proyek ini dikembangkan sebagai luaran penelitian Karya Tulis Ilmiah (KTI) / Tugas Akhir di Program Studi S1 Pendidikan Informatika, Universitas Ivet Semarang.📌 Latar Belakang MasalahUjian daring menggunakan platform formulir biasa sering menghadapi dua masalah nyata di kelas:Integritas Ujian: Mahasiswa sangat mudah berpindah tab browser untuk menyalin soal ke generator AI (seperti ChatGPT), mencari jawaban di mesin pencari, atau saling berkirim jawaban tanpa terdeteksi pengawas.Beban Koreksi Esai: Dosen sering menghindari soal esai karena memeriksa puluhan lembar jawaban mahasiswa secara manual memakan waktu berminggu-minggu, sehingga umpan balik nilai sering terlambat.ExamGuard CBT menyelesaikan kedua masalah tersebut langsung dari sisi peramban web: mengunci fokus ujian mahasiswa dan menyediakan rekomendasi nilai esai otomatis berbasis kemiripan teks.✨ Fitur Utama1. Proteksi Layar & Anti-Kecurangan (Sisi Mahasiswa)Anti-Tab Switching: Mendeteksi secara langsung saat mahasiswa berpindah tab browser, membuka jendela lain, atau me-minimize peramban (Page Visibility API & Window Blur Event).Pemaksaan Layar Penuh (Force Fullscreen): Ujian hanya bisa dikerjakan dalam mode layar penuh. Menekan tombol Esc akan tercatat sebagai pelanggaran.Toleransi Pelanggaran Bertingkat: Memberikan modal peringatan pelanggaran (misalnya batas 3 kali). Jika ambang batas dilanggar, sistem langsung mengunci dan mengirimkan lembar ujian secara paksa (auto-submit).Proteksi Salin-Tempel (Clipboard & Context Lock): Mematikan fungsi klik kanan, seleksi/blok teks, serta kombinasi tombol pintas (Ctrl+C, Ctrl+V, Ctrl+U, F12).Pengacakan Soal: Urutan soal dan opsi pilihan ganda diacak otomatis per mahasiswa (Fisher-Yates Shuffle), sehingga mahasiswa yang bersebelahan tidak mendapatkan urutan yang sama.2. Evaluasi Otomatis & Validasi Dosen (Sisi Pengajar)Koreksi Pilihan Ganda Instan: Nilai pilihan ganda terhitung 100% otomatis segera setelah mahasiswa menyelesaikan ujian.Asisten Penilaian Esai (Cosine Similarity):Teks jawaban mahasiswa diproses melalui pre-processing (pembersihan tanda baca, penghapusan stopword, dan stemming bahasa Indonesia).Menghitung tingkat kedekatan konsep jawaban mahasiswa terhadap kunci jawaban dosen menggunakan pembobotan TF-IDF dan Cosine Similarity.Menghasilkan estimasi skor rekomendasi otomatis ($0 - 100\%$).Dashboard Koreksi Dosen (Human-in-the-Loop): Dosen dapat meninjau jawaban mahasiswa dan kunci jawaban secara berdampingan (side-by-side). Skor rekomendasi dari sistem dapat langsung disetujui atau disesuaikan secara manual sebelum nilai akhir dipublikasikan.Live Monitoring: Pengawas dapat melihat daftar mahasiswa yang sedang aktif mengerjakan, durasi waktu tersisa, dan rekaman log pelanggaran keluar tab secara real-time.🛠️️ Tumpukan Teknologi (Tech Stack)Frontend: Tailwind CSS, JavaScript (Vanilla / React)Backend: PHP (Laravel) / Python / Node.jsDatabase: MySQL / PostgreSQLAlgoritma Utama:Pengacakan: Fisher-Yates ShufflePengolahan Teks: TF-IDF & Cosine Similarity Vector Space ModelAPI Peramban: HTML5 Fullscreen API, Page Visibility API🚀 Panduan Menjalankan Proyek di LokalPrasyaratGitWeb Server & Database (XAMPP / Laragon / Docker)PHP >= 8.1 / Composer (atau Node.js runtime sesuai kebutuhan backend)
